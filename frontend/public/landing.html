The framework

Five pillars, and nothing decorative between them.

Every part of the system answers to one of these. A feature that serves none of them is not in the repository.

P

Performance

348.8 tok/s decode with CUDA graphs, a static KV cache, and BF16 mixed precision.

A

Architecture

Decoder-only Transformer with rotary position embeddings, SwiGLU activations and grouped-query attention.

C

Capability

A real tool loop: read, edit, search, run commands, index symbols, and roll the whole workspace back through Time Machine snapshots.

E

Evaluation

Tracked validation runs: 80.2% loss reduction and 99.8% perplexity reduction, with before and after generation benchmarks.

S

Security

Strict path boundaries, an approval prompt on every file mutation, and keys kept off the API response surface.

What is here

The whole stack is inspectable.

local model

A Transformer you can read end to end

11.3M, 78.7M and 283M parameter configurations, all trainable on a consumer GPU. The byte-level BPE tokenizer was trained on this repository's own source and is lossless at 4,096 tokens.

providers

Bring your own backend

Anthropic, OpenAI, Google, Groq, DeepSeek, Mistral, xAI, Ollama and any OpenAI-compatible endpoint.

approval

Every write is a decision

Mutating calls stop and show the path they are about to touch before they run.

time machine

Content-addressed snapshots

The workspace is snapshotted as the agent works, with branch, diff and restore. A bad turn costs you nothing.

terminal

A shell that remembers

cd, environment variables and activated virtualenvs survive between commands.

skills

Standing directives

Named blocks that shape how the agent works, toggled at will.

distillation

Train the local checkpoint with no hosted API in the loop

A local Ollama teacher generates the training data for the from-scratch model, so the pipeline runs entirely on your own machine.

Quick start

A few commands to a running workspace.

The launcher builds the interface and serves the API from one process. Point it at any folder with --workspace, or pick one from the files panel later without restarting.

Launch workspace Configure API keys Open terminal
powershell
# the environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# torch first, matched to your hardware
pip install torch --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt

# build the interface and serve on 127.0.0.1:8000
python scripts/launch.py --workspace ../my-project
